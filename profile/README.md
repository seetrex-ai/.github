# Seetrex

Deterministic Intelligence: inference that is verifiable, traceable and controllable.
This organization holds the research code and data behind [seetrex.com](https://seetrex.com).
Papers, with their Zenodo records, are listed at [tabares.eu](https://tabares.eu).

| Repository | Paper or report |
|---|---|
| [seetrex-warden-civbench-pilot](https://github.com/seetrex-ai/seetrex-warden-civbench-pilot) | Seetrex Warden on the Ground Control scenario of CivBench, a pre-registered pilot (n = 1 per arm). [doi:10.5281/zenodo.23528741](https://doi.org/10.5281/zenodo.23528741) |
| [laimark](https://github.com/seetrex-ai/laimark) | Laimark: gains and structural limits of self-generated curricula in RLVR. [doi:10.5281/zenodo.19639750](https://doi.org/10.5281/zenodo.19639750) |
| [monolith](https://github.com/seetrex-ai/monolith) | Monolith: differentiable EML trees for symbolic regression. [doi:10.5281/zenodo.19592925](https://doi.org/10.5281/zenodo.19592925) |
| [geood](https://github.com/seetrex-ai/geood) | The geometric blind spot of perplexity: when low loss hides out-of-distribution. [doi:10.5281/zenodo.19039653](https://doi.org/10.5281/zenodo.19039653) |
| [kuraformer](https://github.com/seetrex-ai/kuraformer) | KuraFormer (archived). Version 2 of the paper corrects the original claims: the oscillatory dynamics add nothing over a static adapter. [doi:10.5281/zenodo.19007694](https://doi.org/10.5281/zenodo.19007694) |
